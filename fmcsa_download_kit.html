Motor Carrier Census Data

Official name: Company Census File (dataset az4n-8mr2)

One row per carrier

Identity, status, fleet size (power units, drivers), self-reported VMT (MCS-150 mileage and year), hazmat and revocation flags. Includes active, inactive, and pending registrations. About 1.5 GB uncompressed.

Download CSV dataset page

Large Truck and Bus Crash Data

Official name: Crash File (dataset aayw-vxb3)

One row per crash involvement

State police crash reports for motor carrier vehicles: date, location, severity (fatalities, injuries, tow-away), recordability flags, conditions. A multi-carrier crash appears once per involved carrier. About 2 GB uncompressed.

Download CSV dataset page

Motor Carrier Inspection Data

Official name: Vehicle Inspection File (dataset fx4q-ay7w)

One row per roadside inspection

Inspection level, date, state, and violation / out-of-service totals (driver, vehicle, hazmat). Rolling three-year window (2023-05 to 2026-05 at retrieval). About 3 GB uncompressed.

Download CSV dataset page

Exports are generated server-side and can take a minute before the download starts. All three files key on dot_number. Documentation: FMCSA Open Data Program.
